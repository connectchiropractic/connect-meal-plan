# Connect Meal Plan Maker

The Connect Chiropractic meal plan web app, served by GitHub Pages at
https://mealplan.connectchiropractic.com

- `index.html` is the whole app.
- `data/stores.json` holds this week's flyer deals, towns and regular prices. It is refreshed weekly.
- `data/recipes.json` holds the recipe library (titles, links and main ingredients only; recipes live on their own sites).
- `assets/` holds the logo and home-screen icons.
